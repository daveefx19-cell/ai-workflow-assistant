# AI Workflow Assistant

A portfolio project that turns a business request into a structured automation plan.

## Features
- Workflow trigger and step planning
- Suggested tools and data flow
- Safeguards and test cases
- Optional OpenAI API integration
- Demo mode works without an API key

## Run locally
1. Install Node.js 20+
2. Run `npm install`
3. Copy `.env.example` to `.env`
4. Add an OpenAI API key for live AI mode (optional)
5. Run `npm start`
6. Open `http://localhost:3000`

## Portfolio
This project demonstrates REST API design, server-side API integration, JSON structured output, workflow design, validation, and error handling.
